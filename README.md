# APEX AI 주식매매 봇

휴대폰 브라우저에서 사용하는 Streamlit 기반 AI 백테스트 웹앱입니다.

## 주요 기능
- 한국·미국 주식 데이터 불러오기
- EMA, RSI, MACD, ATR, 거래량 지표 계산
- Random Forest 기반 상승확률 추정
- 학습구간과 검증구간 분리
- 수수료·슬리피지·손절·익절 반영
- 전략수익률, 최대낙폭, 승률, Profit Factor 표시
- 거래내역 CSV 저장

## Streamlit 배포 설정
- Repository: `dg4200355-arch/apex-ai-trading-bot`
- Branch: `main`
- Main file path: `streamlit_app.py`

## 주의
연구 및 모의투자용이며 미래 수익을 보장하지 않습니다. 실계좌 자동주문 기능은 포함되어 있지 않습니다.
