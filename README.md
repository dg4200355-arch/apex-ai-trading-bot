# APEX Autonomous Validation v8.6

한국·미국 주식을 대상으로 **후보를 찾는 것보다 잘못된 후보를 탈락시키는 것**에 초점을 둔 Streamlit 기반 연구·모의투자 시스템입니다.

> 이 프로젝트는 실제 주문을 실행하지 않습니다. 백테스트·통계검증·전진 모의추적 결과는 미래 수익을 보장하지 않습니다.

## 자동 검증 파이프라인

### ① 80종목 전체 스캔
- 한국 40 + 미국 40을 매 실행마다 전부 검사
- 추세 / 반전 / 돌파 / AI 전략 경쟁
- 다음날 시가 체결 기준 백테스트
- 거래비용 반영
- TEST 구간 완전 분리
- 타이밍 순환검정
- Benjamini-Hochberg 다중검정의 family size를 80으로 고정
- 선택 전략의 **정확한 파라미터, 데이터 시작일, 데이터 기준일**을 결과에 동결 저장
- OHLCV 중복 날짜, 잘못된 High/Low, 비정상 가격/거래량을 사전 차단

### ② 완전 동결 2차 확인
1차에서 저장된 전략과 파라미터를 그대로 사용합니다. 2차에서 더 좋은 전략을 다시 고르지 않습니다.

- 1차 TEST 수익률 재현검사
- 거래비용 3단계 스트레스
- 주변 파라미터 흔들기
- 동일 파라미터 10년 구간 스트레스
- 재현오차가 허용치를 넘으면 자동 보류

### ③ 전진 모의추적
2차 확인후보의 전략을 고정하고 후보 등록 이후 새 시장 데이터만 누적합니다.

- 신호는 종가에서 확정
- 거래는 다음 거래일 시가에 체결된 것으로 모의 계산
- 자동 실행이 빠진 날이 있어도 누락된 거래일을 순서대로 재생
- 기존 후보도 현재 동결 2차 검증과 **전략 종류 + 파라미터가 정확히 일치해야 `FROZEN_VERIFIED`**
- AI 후보는 등록 당시 학습 cutoff도 고정

### ④ 최종 전진증거 게이트
다음 조건을 모두 만족하기 전에는 `전진검증완료`로 승격하지 않습니다.

- `FROZEN_VERIFIED`
- 최소 60거래일 관측
- 최소 5회 완료거래
- 전진 누적수익 > 0
- 전진 MDD -10% 이내
- 승률 40% 이상
- PF 1.10 이상
- 추가 왕복비용 스트레스 후에도 수익 > 0
- 거래수익 부트스트랩 양수확률 70% 이상
- 거래 방향성 sign-test
- 추적 후보 전체에 대한 BH 다중검정 통과

30거래일 이상 관측 후 전진수익 -10% 이하 또는 MDD -15% 이하이면 `전진실패`로 표시하며 기록을 삭제하지 않습니다.

### ⑤ 포트폴리오 중복위험·군집대표 게이트
개별 후보가 좋아도 서로 같은 위험을 반복 보유하지 않도록 검사합니다.

- 최근 1년 일간수익률 상관관계 계산
- 최소 공통 120거래일 요구
- 상관계수 0.80 이상이면 같은 중복위험 군집으로 표시
- 같은 고상관 군집에서 여러 종목이 동시에 `전진검증완료`가 되면 **전진수익 → 부트스트랩 양수확률 → PF → MDD → 완료거래수** 순으로 더 강한 1개를 군집 대표로 선택
- 군집 대표 1개만 포트폴리오 허용 대상으로 남기고 나머지는 `고상관군집비대표`로 차단

## 자동 실행

GitHub Actions가 평일 자동으로 아래 순서를 실행합니다.

`80종목 전체검증 → 동결 2차확인 → 전진모의 → 최종 증거게이트 → 포트폴리오 상관/군집대표 게이트`

리포트는 `reports/` 폴더에 저장되고 Streamlit 첫 화면에서 최신 상태를 읽습니다.

주요 파일:
- `reports/latest_validation.csv`
- `reports/latest_confirmation.csv`
- `reports/paper_forward.csv`
- `reports/promotion_status.csv`
- `reports/portfolio_risk.csv`

## 주요 코드
- `engine.py` — 전략/AI/백테스트 엔진
- `market_data.py` — 공통 OHLCV 다운로드 및 무결성 검사
- `tools/autonomous_scan.py` — 80종목 전체 검증
- `tools/stress_confirm.py` — 동결 2차 검증
- `tools/paper_forward.py` — 전진 모의추적
- `tools/promotion_gate.py` — 최종 통계 승격 게이트
- `tools/portfolio_gate.py` — 포트폴리오 중복위험 및 군집 대표 선택
- `streamlit_app.py` — 모바일/웹 대시보드
- `tests/` — 미래정보 누수, 실행 타이밍, 데이터 품질, 동결 파라미터, 통계/포트폴리오 게이트 자동 테스트
